# Lung & Colon Cancer Classification

Deep Learning project using CNN to classify histopathology images into five classes.

## Classes
- Colon Adenocarcinoma
- Colon Normal
- Lung Adenocarcinoma
- Lung Normal
- Lung Squamous Cell Carcinoma

## Technologies
- Python
- TensorFlow / Keras
- OpenCV
- Streamlit

## Accuracy

99.44%
